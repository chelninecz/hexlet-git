# Блэкджек в Excel на формулах (без VBA)

## 📋 Описание

Это полностью функциональная игра «Блэкджек», реализованная **исключительно на формулах Excel** без использования VBA, макросов или любого другого кода.

### Файл
- **Имя:** `Blackjack_Formulas_Only.xlsx`
- **Формат:** `.xlsx` (без макросов)
- **Требуемая версия Excel:** Microsoft 365 / Excel 2021+ (требуется поддержка динамических массивов, LAMBDA, LET, MAP, TEXTJOIN)

---

## 🎮 Как играть

### Начало игры

1. **Откройте файл** `Blackjack_Formulas_Only.xlsx` в Excel
2. **Измените Seed** (ячейка `B3`) — любое число от 1 до 1 000 000
   - Это определит порядок карт в колоде
   - Одинаковый Seed = одинаковая колода
3. **Количество карт игрока** (ячейка `B4`) — по умолчанию 2
4. **Stand** (ячейка `B5`) — по умолчанию FALSE

### Ход игры

#### Взять карту (Hit)
- Увеличьте значение в ячейке `B4` (например, с 2 до 3)
- Игрок получит дополнительную карту из колоды
- Карты не меняются при изменении Seed

#### Остановиться (Stand)
- Измените ячейку `B5` на `TRUE`
- Дилер автоматически доберёт карты до 17+ очков
- Откроются все карты дилера
- Появится результат игры

### Новая игра
Для начала новой раздачи:
1. Измените значение `Seed` (B3)
2. Сбросьте количество карт на 2 (B4)
3. Установите Stand в FALSE (B5)

## 🎯 Правила игры

### Подсчёт очков
- **Туз (A):** 11 или 1 (автоматически подстраивается)
- **Карты 2–10:** по номиналу
- **Валет (J), Дама (Q), Король (K):** 10 очков

### Логика дилера
- Дилер обязан брать карты, пока сумма < 17
- Дилер останавливается на 17 и более (включая Soft 17)
- Если дилер набирает > 21 — он перебрал

### Результаты
| Ситуация | Результат |
|----------|-----------|
| Игрок > 21 | **Перебор игрока** ❌ |
| Stand=FALSE | **Можно взять ещё карту** |
| Блэкджек (A + 10 в первых 2 картах) | **Блэкджек!** |
| Дилер > 21 | **Дилер перебрал** ✅ |
| Очки равны | **Ничья** 🤝 |
| Игрок > Дилер | **Вы выиграли** ✅ |
| Дилер > Игрок | **Дилер выиграл** ❌ |

### Формула генерации колоды

Колода генерируется детерминированно на основе Seed:

```excel
=LET(
    seed, Game!$B$3,
    base, SEQUENCE(52),
    hash1, MOD((base + seed) * 34999 + 12345, 1048576),
    hash2, MOD((base + seed) * 7919 + 104729, 1048576),
    SORTBY(base, hash1, 1, hash2, 1)
)
```

Это обеспечивает:
- ✅ 52 уникальные карты
- ✅ Воспроизводимость (одинаковый Seed = одинаковая колода)
- ✅ Отсутствие летучести (колода не меняется при пересчёте)

### Формула подсчёта очков (HandTotal)

```excel
=LAMBDA(cards,
    LET(
        ranks, MOD(cards - 1, 13) + 1,
        values, IF(ranks = 1, 11, IF(ranks > 10, 10, ranks)),
        total, SUM(values),
        aces, SUM(--(ranks = 1)),
        reduction, IF(total <= 21, 0, MIN(aces, ROUNDUP((total - 21) / 10, 0))),
        total - 10 * reduction
    )
)
```

Логика:
1. Тузам присваивается 11, остальным — номинал
2. Если сумма > 21, тузы уменьшаются на 10 по одному
3. Процесс продолжается пока сумма ≤ 21 или не кончатся тузы

## ✅ Тестовые случаи

### Проверка HandTotal

Протестируйте функцию HandTotal со следующими значениями (в служебной области):

| Карты (коды) | Ожидаемый результат |
|--------------|---------------------|
| Туз + Король (1, 13) | 21 |
| Туз + Туз (1, 14) | 12 |
| Туз + 6 + Король (1, 6, 13) | 17 |
| Туз + 7 + Король (1, 7, 13) | 18 |
| Туз + Туз + Король (1, 14, 13) | 12 |
| 10 + Валет + Дама (10, 11, 12) | 30 |
| 9 + Туз (9, 1) | 20 |

### Проверка колоды

В служебной области (колонки G–H) отображаются проверки:

- ✅ Уникальность: `=ROWS(UNIQUE(Deck)) = 52` → должно быть TRUE
- ✅ Минимум: `=MIN(Deck)` → должно быть 1
- ✅ Максимум: `=MAX(Deck)` → должно быть 52
- ✅ Нет пересечений: `=SUM(--(ISNUMBER(MATCH(PlayerCards, DealerCards, 0)))) = 0` → TRUE

### Проверка воспроизводимости

1. Установите Seed = 12345
2. Запомните первые 3 карты игрока
3. Измените Seed на 99999
4. Верните Seed = 12345
5. Первые 3 карты должны совпасть с шагом 2

## ⚠️ Известные ограничения

1. **Excel-формулы ≠ игровой движок**
   - Без VBA невозможно сделать кнопки с действиями
   - Управление через изменение ячеек

2. **Нет истории игр**
   - Без VBA сложно хранить историю раздач
   - Каждая новая игра требует ручного сброса

3. **Нет банка и ставок**
   - Реализация потребовала бы циклических ссылок или VBA

4. **Псевдослучайность**
   - Детерминированный генератор на основе Seed
   - Не является криптографически стойким
   - Достаточно для учебной игры

5. **Требования к версии Excel**
   - Требуется Excel 365 / 2021+ для поддержки:
     - Динамических массивов (SEQUENCE, SORTBY, TAKE, DROP)
     - Функций LAMBDA, LET, MAP
     - TEXTJOIN

6. **Упрощённые правила**
   - Нет Split, Double Down, Insurance, Surrender
   - Дилер всегда останавливается на Soft 17
   - Одна колода из 52 карт

## 🛠️ Создание элементов управления (опционально)

Если вы хотите добавить визуальные элементы управления:

### Счётчик для количества карт (B4)

1. Перейдите на вкладку **Разработчик** (Developer)
2. Нажмите **Вставить** → **Элементы управления формы** → **Счётчик** (Spin Button)
3. Нарисуйте элемент рядом с ячейкой B4
4. Щёлкните правой кнопкой → **Формат объекта**
5. Укажите:
   - Минимальное значение: 2
   - Максимальное значение: 20
   - Изменение ячейки: `$B$4`
6. Нажмите OK

### Флажок для Stand (B5)

1. Вкладка **Разработчик** → **Вставить** → **Флажок** (Checkbox)
2. Нарисуйте элемент рядом с ячейкой B5
3. Щёлкните правой кнопкой → **Формат объекта**
4. Укажите:
   - Ячейка связи: `$B$5`
5. Удалите текст флажка (оставьте только галочку)
6. Нажмите OK

**Примечание:** Эти элементы работают без макросов, просто изменяя связанные ячейки.
