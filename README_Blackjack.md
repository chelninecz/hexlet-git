# Блэкджек в Excel на формулах (без VBA)

## 📋 Описание

Это полностью функциональная игра «Блэкджек» реализованная **исключительно на формулах Excel** без использования VBA, макросов или любого другого кода.

### Требования
- **Microsoft 365 / Excel 2021+** (требуется поддержка динамических массивов и LAMBDA)
- Файл формата `.xlsx` (не содержит макросов)

---

## 🎮 Как играть

### Начало игры
1. Откройте файл `Blackjack_Formulas_Only.xlsx`
2. В ячейке **B1** (`Seed`) введите любое число от 1 до 1 000 000 — это определит колоду
3. В ячейке **B2** (`Карт игрока`) установите количество карт (минимум 2)
4. В ячейке **B3** (`Stand`) установите `FALSE` для продолжения игры

### Ход игрока
- **Взять карту (Hit)**: Увеличьте значение в ячейке **B2** (например, с 2 до 3)
- **Остановиться (Stand)**: Установите **B3** в `TRUE`

### Результат
После установки `Stand=TRUE`:
- Дилер автоматически доберёт карты до суммы ≥ 17
- В ячейке **C16** отобразится результат игры
- Ячейка результата подсветится цветом:
  - 🟥 **Красный**: Перебор игрока
  - 🟩 **Зелёный**: Победа
  - 🟨 **Жёлтый**: Ничья
  - ⬜ **Серый**: Игра продолжается

### Новая игра
1. Измените значение **Seed** (B1)
2. Сбросьте **B2** к 2
3. Установите **B3** в `FALSE`

## 📐 Структура листа

### Входные ячейки
| Ячейка | Имя | Описание | Проверка данных |
|--------|-----|----------|-----------------|
| B1 | SeedValue | Seed для генерации колоды | Целое 1–1 000 000 |
| B2 | PlayerN | Количество карт игрока | Целое 2–20 |
| B3 | Stand | Флаг остановки | TRUE/FALSE |

### Выходные ячейки
| Ячейка | Формула | Описание |
|--------|---------|----------|
| C9 | =PlayerHandDisplay | Карты игрока текстом |
| C10 | =PlayerTotal | Сумма очков игрока |
| C12 | =DealerVisibleDisplay | Видимая карта дилера |
| C13 | =DealerHandDisplay | Полная рука дилера |
| C14 | =DealerTotal | Очки дилера |
| C16 | =GameResult | Результат игры |

### Отладочная область (строки 20–28)
| Ячейка | Формула | Описание |
|--------|---------|----------|
| A22 | =TEXTJOIN(..., DeckDebug) | Первые 10 карт колоды |
| C23 | =PlayerN | Карт игрока |
| C24 | =DealerN | Карт дилера |
| C25 | =IF(ROWS(UNIQUE(Deck))=52,...) | Проверка уникальности |
| C26 | =MIN(Deck) | Минимальная карта |
| C27 | =MAX(Deck) | Максимальная карта |
| C28 | =SUM(...MATCH...) | Пересечение рук |

## 🔧 Именованные диапазоны и формулы

### Основные переменные
| Имя | Формула | Описание |
|-----|---------|----------|
| **PlayerN** | `=MIN(MAX(Game.$B$2, 2), 20)` | Карт игрока (ограничено) |
| **Stand** | `=Game.$B$3` | Флаг остановки |
| **SeedValue** | `=Game.$B$1` | Seed колоды |

### Колода
| Имя | Формула | Описание |
|-----|---------|----------|
| **Deck** | `=LET(s,SeedValue,base,SEQUENCE(52),h1,MOD((base+s)*34999+12345,1048576),h2,MOD((base+s)*7919+104729,1048576),SORTBY(base,h1,1,h2,1))` | Детерминированная колода |
| **DeckDebug** | `=TAKE(Deck,10)` | Первые 10 карт |
| **PlayerCardsRaw** | `=TAKE(Deck,PlayerN)` | Карты игрока |
| **Remaining** | `=DROP(Deck,PlayerN)` | Оставшиеся карты |

### LAMBDA функции
| Имя | Описание |
|-----|----------|
| **HandTotal** | Подсчёт очков руки с учётом тузов (11 или 1) |
| **CardName** | Преобразование кода карты в текст (A♠, 10♥ и т.д.) |
| **HandDisplay** | Отображение всей руки текстом |
| **DealerNCalc** | Расчёт количества карт дилера (до 17) |

### Результаты
| Имя | Формула | Описание |
|-----|---------|----------|
| **PlayerTotal** | `=HandTotal(PlayerCardsRaw)` | Очки игрока |
| **DealerN** | `=IF(Stand,DealerNCalc(Remaining),2)` | Карт дилера |
| **DealerCardsRaw** | `=TAKE(Remaining,DealerN)` | Карты дилера |
| **DealerTotal** | `=IF(Stand,HandTotal(DealerCardsRaw),...)` | Очки дилера |
| **DealerVisibleDisplay** | `=IF(Stand,HandDisplay(...),CardName(...) & "  ?")` | Видимая карта |
| **DealerHandDisplay** | `=IF(Stand,HandDisplay(...),"?")` | Полная рука |
| **GameResult** | `=LET(p,PlayerTotal,d,IF(Stand,DealerTotal,0),...)` | Результат |

## 🎯 Правила игры

### Обязательные правила
1. Одна колода из 52 карт
2. Карты не возвращаются в колоду
3. Туз = 11 или 1 (автоматически)
4. J, Q, K = 10
5. Дилер берёт до 17 (включая soft 17)
6. Перебор (>21) = проигрыш

### Упрощения
- ❌ Нет Split
- ❌ Нет Double Down
- ❌ Нет Insurance
- ❌ Нет Surrender
- ❌ Нет выплат 3:2 за блэкджек

### Результаты
| Состояние | Сообщение |
|-----------|-----------|
| Игрок > 21 | «Перебор игрока» |
| Дилер > 21 | «Дилер перебрал» |
| Равны | «Ничья» |
| Игрок > Дилер | «Вы выиграли» |
| Дилер > Игрок | «Дилер выиграл» |
| Stand=FALSE | «Можно взять ещё карту» |

## ✅ Тестовые случаи

### Проверка HandTotal
| Карты (коды) | Ожидаемая сумма |
|--------------|-----------------|
| Туз + Король (1, 13) | 21 |
| Туз + Туз (1, 14) | 12 |
| Туз + 6 + Король (1, 6, 13) | 17 |
| Туз + 7 + Король (1, 7, 13) | 18 |
| 10 + Валет + Дама (10, 11, 12) | 30 |
| 9 + Туз (9, 1) | 20 |

### Проверка колоды
- [ ] В колоде ровно 52 карты (ячейка C25 = "OK")
- [ ] Минимум = 1 (ячейка C26)
- [ ] Максимум = 52 (ячейка C27)
- [ ] При одном Seed колода одинаковая
- [ ] При разных Seed колода меняется

### Проверка раздачи
- [ ] PlayerCards содержит ровно PlayerN карт
- [ ] DealerCards не пересекается с PlayerCards (C28 = 0)
- [ ] При увеличении PlayerN карты добавляются

### Проверка дилера
- [ ] Дилер останавливается при ≥ 17
- [ ] Если дилер перебрал, сумма > 21
- [ ] До Stand видна только первая карта

### Проверка результата
- [ ] При >21 у игрока: «Перебор игрока»
- [ ] При Stand и дилер >21: «Дилер перебрал»
- [ ] При равных: «Ничья»
- [ ] При игроке > дилера: «Вы выиграли»

## ⚠️ Известные ограничения

1. **Требуется Excel 365/2021+** — используются LAMBDA, динамические массивы
2. **Нет кнопок** — управление через ячейки
3. **Нет банка/ставок** — требует VBA или циклических ссылок
4. **Псевдослучайность** — детерминированный seed, не криптография
5. **Нет истории игр** — только текущая раздача
6. **Сброс вручную** — Stand не сбрасывается автоматически

## 🛠️ Создание элементов управления (опционально)

### Счётчик для карт игрока (B2)
1. Разработчик → Вставить → Элементы управления формы → Счётчик
2. Нарисовать рядом с B2
3. ПКМ → Формат объекта →
   - Текущее значение: 2
   - Минимум: 2
   - Максимум: 20
   - Изменение ячейки: $B$2

### Флажок для Stand (B3)
1. Разработчик → Вставить → Элементы управления формы → Флажок
2. Нарисовать рядом с B3
3. ПКМ → Формат объекта →
   - Связать с ячейкой: $B$3
   - Значение: Unchecked=False, Checked=True

## 📝 Примечания по локализации

Если у вас русская версия Excel, возможно потребуется адаптировать:
- Разделители аргументов: `,` → `;`
- Имена функций: `IF` → `ЕСЛИ`, `SUM` → `СУММ` и т.д.

В сгенерированном файле используется английский синтаксис, который работает в большинстве версий Excel.
