# 🃏 Блэкджек в Excel (версия для русской локализации)

## ✅ Файл готов
**Blackjack_RU_Locales.xlsx** — игра работает только на формулах, без VBA и макросов.

---

## 🎮 Как играть

### 1. Откройте файл
Откройте `Blackjack_RU_Locales.xlsx` в **Excel 2021 или Microsoft 365** (требуется поддержка LAMBDA и динамических массивов).

### 2. Начните новую игру
| Ячейка | Параметр | Значение |
|--------|----------|----------|
| **B1** | Seed для новой игры | Любое целое число от 1 до 1 000 000 |
| **B2** | Карт игрока (Hit) | Минимум 2 (увеличивайте для взятия карт) |
| **B3** | Stand (Остановиться) | FALSE (игра идёт) / TRUE (стоп) |

### 3. Ход игры
1. **Измените Seed (B1)** — это создаст новую уникальную колоду
2. **Увеличьте B2** с 2 до 3, 4, 5... чтобы взять дополнительные карты (Hit)
3. Когда решите остановиться, **установите B3 = TRUE** (Stand)
4. Посмотрите результат в ячейке **B10**

### 4. Новая раздача
Для начала новой игры:
1. Измените значение Seed (B1)
2. Сбросьте B2 обратно на 2
3. Установите B3 = FALSE

## 📋 Что отображается

| Ячейка | Описание |
|--------|----------|
| **B6** | Рука игрока (например: `A♠  10♥`) |
| **B7** | Очки игрока (с учётом тузов как 1 или 11) |
| **B8** | Рука дилера (до Stand показывает первую карту + `?`) |
| **B9** | Очки дилера (после Stand) |
| **B10** | **Результат игры** (цветная подсветка) |

### Возможные результаты:
- 🟥 **Перебор игрока** — у игрока > 21 очка
- 🟩 **Вы выиграли** — у игрока больше очков
- 🟩 **Дилер перебрал** — у дилера > 21 очка
- 🟨 **Ничья** — равные очки
- 🟦 **Дилер выиграл** — у дилера больше очков
- ⬜ **Можно взять ещё карту** — игра продолжается (Stand = FALSE)

## 🔧 Технические детали

### Именованные диапазоны (формулы)
| Имя | Описание |
|-----|----------|
| `SeedVal` | Значение из B1 |
| `Deck` | Колода 52 карты (детерминированное перемешивание) |
| `PlayerCards` | Массив карт игрока |
| `DealerCards` | Массив карт дилера |

| `PlayerTotal` | Сумма очков игрока |
| `DealerTotal` | Сумма очков дилера |
| `CardNameFunc` | LAMBDA-функция отображения карты (например, "K♦") |
| `HandDisplay` | Текстовое отображение руки игрока |
| `DealerDisplay` | Текстовое отображение руки дилера (со скрытием) |

### Проверка данных
- **B1**: целое число 1–1 000 000
- **B2**: целое число 2–20
- **B3**: список FALSE, TRUE

### Условное форматирование (ячейка B10)
- 🟥 Красный: Перебор игрока
- 🟩 Зелёный: Победа (Вы выиграли / Дилер перебрал)
- 🟨 Жёлтый: Ничья
- ⬜ Серый: Игра продолжается

## ⚠️ Важные примечания

### Требования к Excel
- **Microsoft 365** или **Excel 2021+**
- Необходима поддержка функций: `LAMBDA`, `LET`, `MAP`, `TEXTJOIN`, `SEQUENCE`, `SORTBY`, `TAKE`, `DROP`, `UNIQUE`

### Локализация
- Формулы в файле записаны на **английском синтаксисе** (стандарт OOXML)
- При открытии в **русской версии Excel** функции автоматически отобразятся на русском:
  - `LAMBDA` → `ЛЯМБДА`
  - `LET` → `ПУСТЬ`
  - `IF` → `ЕСЛИ`
  - `SEQUENCE` → `ПОСЛЕДОВ`
  - и т.д.
- Разделитель аргументов: точка с запятой (`;`)

### Известные ограничения
1. ❌ Нет Split, Double Down, Insurance, Surrender (упрощённые правила)
2. ❌ Нет системы ставок и банка (требует VBA или циклических ссылок)
3. ❌ Управление через ячейки, а не кнопки
4. ❌ Псевдослучайность (не криптографическая, но воспроизводимая)
5. ❌ При новой игре нужно вручную сбрасывать B2 и B3

## 🧪 Тестирование

### Проверка колоды
Ячейка **B14** должна показывать `OK` (все 52 карты уникальны)

### Примеры тестов
1. **Seed = 12345, Карт = 2, Stand = FALSE**
   - Должны быть видны 2 карты игрока
   - У дилера: первая карта + `?`
   - Результат: "Можно взять ещё карту"

2. **Seed = 12345, Карт = 2, Stand = TRUE**
   - Дилер доберёт карты до суммы ≥ 17
   - Результат: один из вариантов победы/поражения/ничьей

3. **Проверка тузов**
   - Если у игрока Туз + Туз + Король = 12 очков (не 32)
   - Если Туз + 10 = 21 (блэкджек)

## 🛠️ Если что-то не работает

1. **#ИМЯ? ошибка** — ваша версия Excel не поддерживает LAMBDA (нужен Excel 2021+/365)
2. **#CALC! ошибка** — проверите, что B2 в диапазоне 2–20
3. **Колода не меняется** — измените Seed (B1)
4. **Формулы на английском** — откройте в русской версии Excel, они переведутся автоматически
